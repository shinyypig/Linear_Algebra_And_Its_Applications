[`../AGENTS.md`](../AGENTS.md)，章节进度与候选目录见
[`../BOOK_PLAN.md`](../BOOK_PLAN.md)。

## 预留的指南

下列文件暂不建立。表中的名称用于提前划分职责，并不表示其中的规则已经确定。

| 预留文件 | 建立时机 | 预计内容 |
| --- | --- | --- |
| `SOLUTION_STYLE_GUIDE.md` | 开始系统编写习题答案时 | 解答详略、步骤、提示、答案编号与验算要求 |
| `BIBLIOGRAPHY_AND_CITATION_GUIDE.md` | 正文开始正式引用资料时 | 文献选择、引文位置、BibLaTeX 字段与引用格式 |
| `COMPUTATION_GUIDE.md` | 引入可执行计算或数值实验时 | 代码位置、随机种子、精度、复现和结果核验 |
| `FIGURE_CATALOG.md` | 图片数量增多且难以检索时 | 图片用途、源文件、正文位置和复用关系 |

实际任务出现前，不应仅为“完整”而创建空指南。若一类规则只有少数几条，先补入最
接近的现有指南；规则稳定且职责明显独立后，再建立新文件。

## 维护原则

- 一个约定只保留一个主要出处，其他文件通过链接引用，避免多份规则逐渐不一致。
- 全书共用且必须优先看到的规则保留在 `AGENTS.md`，细节放入专项指南。
- 章节安排和写作进度只维护在 `BOOK_PLAN.md`，不在本目录复制一份目录。
- 新增、重命名或停用指南时，同步更新本索引和 `AGENTS.md` 的任务路由表。
- “待定”内容不能被 AI 当作作者已经批准的方案；实际采用后才能升级为正式规则。
