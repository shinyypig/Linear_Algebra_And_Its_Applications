# 数学记号指南

本指南记录《线性代数及应用》已经采用的统一数学记号，并为后续章节预留需要决策的
项目。编辑正文时，应优先沿用“已确定”部分；“待定”部分仅用于提醒，不能据此自行
引入新记号。

## 1. 一般原则

- 同一对象在全书中使用同一类字母和字形；局部确需改变时，应在正文中明确说明。
- 新记号首次出现时必须定义，不能只依赖读者从上下文猜测。
- 字母选择应体现对象类型，但不能为了追求形式统一而改写已有的大段内容。
- 向量、集合、空间、映射和数值不变量应在字形上保持可辨认。
- 一个符号不得在相邻内容中同时承担两个不同含义。

## 2. 已确定的记号

### 2.1 集合与映射

- 一般集合使用大写拉丁字母 \(A,B,C\)，元素使用小写拉丁字母 \(a,b,c\)。
- 数集使用 `\mathbb` 字体，如 `\mathbb N`、`\mathbb Z`、`\mathbb Q`、
  `\mathbb R` 和 `\mathbb C`。
- 映射写作 `f:A\to B`；定义域、陪域、像与原像的写法沿用第一章已经建立的记号。
- 空集写作 `\varnothing`，不使用形似希腊字母的替代符号。

### 2.2 代数结构

- 一般群使用 \(G,H\)，一般环使用 \(R\)，一般域使用 `\mathbb F`。
- 模 \(n\) 的整数环使用 `\mathbb Z_n`；若后文需要更精确地区分商环记法，应先在
  正文中说明。
- 二元运算可以使用 `\ast` 等抽象符号；已经明确为加法或乘法时使用 \(+\) 或普通
  乘法记号。
- 单位元和逆元的记号服从具体运算。使用加法记号时写零元与负元，使用乘法记号时写
  单位元与逆元。

### 2.3 向量与向量组

- 向量使用粗体小写字母，如 `\bm u`、`\bm v`、`\bm w`；零向量写作 `\bm 0`。
- 向量的分量使用普通斜体字母并加下标，如 \(v_i\)。
- 标准单位向量写作 `\bm e_i`。
- 标量通常使用希腊字母，如 \(\lambda,\mu,\alpha,\beta\)，并明确它们属于底域
  `\mathbb F`。
- 有序向量组可写作 `(\bm v_1,\ldots,\bm v_n)`；只关心其中向量而不强调次序时，
  根据上下文使用“向量组”这一表述，不轻率改写成集合。
- 向量组生成的空间写作 `\operatorname{span}(\bm v_1,\ldots,\bm v_n)`；空向量组
  满足 `\operatorname{span}\varnothing=\{\bm 0\}`。
- 有限向量组的秩写作 `\operatorname{rank}(\bm v_1,\ldots,\bm v_n)`。

### 2.4 线性空间与子空间

- 一般线性空间使用 \(V,W\)，子空间通常使用 \(U,S\)。首次出现时必须说明底域。
- 线性空间的维数写作 `\dim V`，不用“秩”指代空间的维数。
- 一组基通常使用花体字母，如 `\mathcal B`；基中的向量仍使用粗体小写字母。
- 多项式空间沿用正文已经采用的 \(\mathcal P_n\) 等记号，并在定义处说明次数范围与
  系数域。
- 若多个空间参与交、和或包含关系，必须先说明它们位于同一个环境空间中。

### 2.5 矩阵

- 一般矩阵使用大写拉丁字母 \(A,B,C\)，矩阵元素相应写作 \(a_{ij},b_{ij},c_{ij}\)。
- \(\mathbb F\) 上的 \(m\times n\) 矩阵空间写作 `M_{m\times n}(\mathbb F)`，
  \(n\) 阶方阵空间简记为 `M_n(\mathbb F)`。
- 零矩阵写作 `O_{m\times n}`，大小明确时简记为 \(O\)；单位矩阵写作 \(I_n\)。
- 第 \(i\) 行第 \(j\) 列为 \(1\)、其余位置为 \(0\) 的矩阵写作 \(E_{ij}\)。
- 转置矩阵写作 \(A^{\mathsf T}\)，逆矩阵写作 \(A^{-1}\)。
- 矩阵的秩写作 `\operatorname{rank}A`，当前定义为列向量组的秩。

### 2.6 线性映射

- 一般线性映射使用 \(T,S\)，写作 \(T:V\to W\)；只在强调定义域与陪域相同时使用
  “线性变换”。
- 从 \(V\) 到 \(W\) 的线性映射空间写作 `\mathcal L(V,W)`，恒等映射写作 \(I_V\)。
- 向量 \(\bm v\) 在基 \(\mathcal B\) 下的坐标向量写作
  `[\bm v]_{\mathcal B}`。
- 线性映射 \(T:V\to W\) 关于定义域基 \(\mathcal B\) 和陪域基 \(\mathcal C\) 的
  表示矩阵写作 `[T]_{\mathcal C\leftarrow\mathcal B}`。
- 核与像分别写作 `\ker T` 和 `\operatorname{im}T`；秩与零化度分别写作
  `\operatorname{rank}T` 和 `\operatorname{nullity}T`。
- 从基 \(\mathcal B'\) 到基 \(\mathcal B\) 的过渡矩阵写作
  `P_{\mathcal B\leftarrow\mathcal B'}`。

### 2.7 排版约定

- 向量使用 `\bm`，数集使用 `\mathbb`，向量组或基等成组对象可使用 `\mathcal`。
- `span`、`rank` 等数学算子使用 `\operatorname{...}`，不直接写成斜体字母串。
- 行内公式使用 `\(...\)`，行间公式使用 `\[...\]`。
- 公式间距只使用 `\quad`，不使用 `\qquad`。
- 正文中的零应根据对象区分为标量 \(0\)、零向量 `\bm 0` 与零矩阵 \(O\)。

## 3. 后续章节待定

以下项目尚未形成全书规则。实际写到相应章节时，应结合前文、常见教材习惯和该章
需求作出决定，再把最终记号移入“已确定”部分。

- 共轭转置与伴随映射的记号；
- 内积、范数、距离、正交补和投影的记号；
- 行列式、特征值、特征向量和特征空间的记号；
- 直和、商空间以及坐标同构的记号；
- 奇异值分解、主成分分析和矩阵微积分中的记号。

确定新记号时至少检查：是否与已有符号冲突，是否需要区分实数域与复数域，是否能
覆盖退化或零维情形，以及是否与后续预期用途相容。

## 4. 维护方式

- 只记录已经在正文中采用或由作者明确确认的规则。
- 新记号一旦进入正文，应同步更新本指南；纯局部临时变量通常无需记录。
- 修改已有规则前，先检索全书中的实际用法，并评估是否需要统一替换。
- 若规则只涉及语言、习题或证明风格，应写入 `TEXTBOOK_WRITING_STYLE_GUIDE.md`，
  不在本文件重复维护。
